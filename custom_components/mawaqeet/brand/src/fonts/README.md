# Brand fonts (OFL)

Variable fonts are downloaded automatically by `scripts/export_wordmark.py` if missing:

| File | Source |
|------|--------|
| `Inter-VF.ttf` | [Inter](https://github.com/google/fonts/tree/main/ofl/inter) (OFL) |
| `NunitoSans-VF.ttf` | [Nunito Sans](https://github.com/google/fonts/tree/main/ofl/nunitosans) (OFL) |
| `NotoSansArabic-VF.ttf` | [Noto Sans Arabic](https://github.com/google/fonts/tree/main/ofl/notosansarabic) (OFL) |

Wordmarks are exported as SVG paths (no live font dependency in committed logos).
